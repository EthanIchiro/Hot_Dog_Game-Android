## What is this

A tiny chaos game where you must protect a delicious hot dog using:

# THE HOT DOG CANNON

Your mission:

1. Move around (with your thumb, fancy person).
2. Protect the hot dog.
3. Shoot the enemy.
4. Accidentally shoot the hot dog.
5. Accidentally shoot yourself.
6. Unlock an achievement for that.
7. Blame the touch controls.
8. Do it again.

Simple.

Built with **100% GDScript**.
No multi-language stack.

## Controls (phone)

| Input | Action |
| --- | --- |
| **Drag LEFT side / stick** | Move YOU + the HOT DOG + the BULLETS |
| **SHOOT** | Fire the cannon (or start from the title) |
| **R** | Restart the chaos |
| **ACH** | Stare at achievements you do/don't have |

Optional fancy mode: Bluetooth keyboard  
Space = shoot · R = restart · Enter/Esc = achievements  

One stick moves lunch AND ammunition.
If that sounds like a design mistake: correct.
If that sounds worse on a phone: also correct.
